# ATOMIC · MUSIC — کتابخانه طراحی اتمیک برای پلتفرم موسیقی

> نه «پروژه» — یک **کتابخانهٔ الگوهای قابل مرور، جستجو و انتخاب** برای پلتفرم موسیقی
> (مدل مرجع: Chordify / Moises — کورد، استم، تمپو، ویوفرم، لیریک).

## ایده

دو پوشهٔ `docs/…` (دیتای مرجع اولیه) به `archive/` منتقل شدند؛ آن‌ها صرفاً مرجع فهم دامنه‌اند.
این ریپو اکنون **طراحی اتمیک** را به شکل زیر نگه می‌دارد:

```
src/
  core/            ← توکن‌ها، تایپ‌ها، رجیستری مرکزی
    registry.ts    ← فهرست همهٔ الگوها (خودکار از meta ها)
  ui/
    atoms/         ← اتم: دکمه، بک‌دکمه، اسلایدر، ناب، سوئیچ، چیپ…
      button/
        index.tsx  ← کامپوننت + واریانت‌ها (CVA)
        meta.ts(x) ← متادیتا: دسته، تگ، منبع، دموها
    molecules/     ← مولکول: کنترل پخش، صدا، تمپو، ویوفرم، EQ، استم
    organisms/     ← ارگانیسم: پلیر، تایم‌لاین، کارت کتابخانه
  catalog/         ← اپ مرور: جستجو، سایدبار سطح/دسته، گالری واریانت + کد
```

## قانونِ «پیدا شدن»

- هر الگو = یک پوشه، هر پوشه = `index.tsx` + `meta.ts[x]`.
- `meta` شامل: نام فارسی/انگلیسی، سطح (atom/molecule/organism)، دسته‌ها، تگ‌ها،
  توضیح، **منبع ارجاع** به دیتای اولیه در `archive/`، و لیست واریانت‌ها (props + snippet).
- کاتالوگ همهٔ این‌ها را خودکار می‌خواند؛ برای افزودن الگوی جدید فقط کافی است
  پوشه بسازی و یک خط به `src/core/registry.ts` اضافه کنی.

## استک

React 19 · TypeScript strict · Vite 8 · Tailwind v4 · CVA (واریانت‌ها) ·
Motion (انیمیشن‌ها) · Radix (اسلایدر/سوئیچ/تول‌تیپ) · Lucide (آیکون‌ها)

## اجرا

```bash
npm install
npm run dev        # کاتالوگ: http://localhost:5173
npm run build      # تایپ‌چک + بیلد
```

## وضعیت فعلی

۲۳ الگو · ۹۵ واریانت تعاملی در ۷ دسته — جستجو را امتحان کن: «بازگشت»، «تمپو»،
«استم»، «انیمیشن»، «mute».
